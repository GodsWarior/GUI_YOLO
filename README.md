# GUI_YOLO: Редактор датасетов и графический интерфейс для YOLOv8

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![YOLO](https://img.shields.io/badge/YOLO-v8-brightgreen.svg)](https://github.com/ultralytics/ultralytics)
[![UI](https://img.shields.io/badge/GUI-PyQt6-red.svg)](https://www.riverbankcomputing.com/software/pyqt/)

**GUI_YOLO** — это кроссплатформенное графическое десктоп-приложение (GUI) для комплексной автоматизации процессов разметки датасетов компьютерного зрения, покадровой нарезки видеопотоков, аннотирования объектов, генерации конфигураций стандартов YOLO (`data.yaml`) и запуска обучения/инференса нейросетевых моделей семейства YOLOv8 в интерактивном режиме.

---

## Ключевые возможности

- ✂️ **Нарезка видео на кадры**: автоматическое извлечение кадров из видеофайлов (`mp4`, `avi` и др.) с настраиваемым шагом и таймстемпами для формирования обучающей выборки.
- 🏷️ **Редактирование датасетов и аннотирование**: интерактивное создание классов разметки, нормализация координат Bounding Box (`x_center`, `y_center`, `width`, `height`) под стандарты YOLO.
- ⚙️ **Генерация `data.yaml`**: автоматическое структурирование папок (`train`, `val`, `test`), подсчет числа классов (`nc`) и экспорт манифеста обучения.
- 🎯 **Инференс в реальном времени**: детектирование объектов на статических изображениях, видеозаписях и через подключенную веб-камеру с отрисовкой рамок и уверенности модели.
- 🚀 **Обучение моделей YOLOv8**: удобная настройка гиперпараметров (число эпох, размер батча, разрешение изображения `imgsz`) и запуск обучения прямо из интерфейса.

## Архитектура проекта

```text
GUI_YOLO/
├── main.py                  # Точка входа в приложение, запуск главного окна Qt
├── GUI.py                   # Главное окно PyQt6, управление страницами, привязка кнопок
├── neural_network.py        # Загрузка камеры, инференс YOLO и отрисовка Bounding Box
├── network_training_etc.py  # Утилиты нарезки видео, нормализация координат, сохранение data.yaml
├── mask_and_neural_network.py # Обработка видеопотоков и отображение с камеры
├── config.json              # Конфигурационный файл приложения и метаданные лицензии
├── data.yaml                # Манифест структуры датасета для обучения YOLO
├── dataset/                 # Директории датасета (train, valid, test)
├── runs/                    # Результаты обучения, веса моделей (.pt) и графики метрик
├── LICENSE                  # Официальный текст лицензии MIT
├── LICENSES.md              # Лицензии сторонних библиотек и компонентов
├── pyproject.toml           # Метаданные пакета Python (PEP 621 / PEP 517)
├── requirements.txt         # Список внешних зависимостей pip
└── README.md                # Документация проекта
```

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/GodsWarior/GUI_YOLO.git
cd GUI_YOLO
```

### 2. Создание виртуального окружения
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python main.py
```
